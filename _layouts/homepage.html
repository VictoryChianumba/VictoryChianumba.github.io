Victory Chianumba

I work on mechanistic interpretability and AI safety research engineering. My current focus is on understanding how sparse autoencoders fail when imported from language models to other substrates, and on building tooling that makes those failures visible. I have an MSc in AI for Engineering and Design from the University of Bath, with a thesis on architectural biases in EEG-based neural networks. I'm based in Bath, UK. Recently I've been building interpretability tooling for transformer world models and investigating factored sparse autoencoders for LLM concept manifolds — both projects below.

Adversarial attacks that evade explanation-based monitoring in EEG classifiers
Victory Chianumba
MSc thesis work, University of Bath
Blog post / Project page / GitHub

TL;DR: Low-pass adversarial perturbations can flip an EEG classifier's prediction while leaving its Integrated Gradients explanation essentially intact. That creates a blind spot for explanation-based attack monitors: the explanation appears stable even when the prediction has been corrupted.
Interpretability tooling for IRIS-class world models
Victory Chianumba
Personal project, 2026
Blog post / GitHub / FINDINGS.md

TL;DR: A working SAE feature explorer for IRIS world models, with a case study showing that activation-magnitude ranking surfaces a different wrong feature each time the SAE is retrained — a structural failure mode of importing LLM-SAE conventions to slow-state substrates.
Factored sparse autoencoders for LLM concept manifolds
Victory Chianumba
Personal project, 2026
WRITEUP.md / GitHub / Goodfire paper

TL;DR: Tested whether factored "atlas-of-charts" SAEs capture curved concept manifolds better than standard linear dictionaries. Found a narrow positive result on geography, several honest negatives elsewhere, and a methodological warning about soft-routing leakage in MoE-style SAE evaluation.
